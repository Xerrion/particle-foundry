## Implemented contract

The f64 CPU reference has bounded substep selection, conservative liquid and carrier phase transport, phase-associated marker transport, compatible face-momentum advection, tangential shear viscosity, gravity, pressure projection, and atomic substep acceptance. The coupled session uses closed walls. Its candidate state is accepted only after the operators and pressure solve succeed; a rejected step leaves the accepted state and time unchanged. The relevant owners are [`transport.rs`](../../engine/crates/sim-cpu/src/transport.rs), [`momentum.rs`](../../engine/crates/sim-cpu/src/momentum.rs), [`viscosity.rs`](../../engine/crates/sim-cpu/src/viscosity.rs), [`substep.rs`](../../engine/crates/sim-cpu/src/substep.rs), and [`coupled.rs`](../../engine/crates/sim-cpu/src/coupled.rs).

This is a CPU numerical reference, not a GPU scene. It has no chemistry or thermal energy/temperature solve. Phase-associated markers are passive extensive quantities. Periodic marker and shear cases are component-level test oracles; the public coupled step supports closed walls only.

These are acceptance thresholds, not measured errors.

The reported front and both centroids move in one direction as the grid is refined. The 2× to 4× gap divided by the 1× to 2× gap is about `0.601` for the front, `0.514` for the x centroid, and `0.315` for the y centroid. These three samples show refinement behavior; they do not establish an asymptotic convergence order. The 4× maximum face-correction CFL is below the current `2.5e-10` code cap by about 4.24%, so this margin is narrow and should remain visible in later solver changes.
