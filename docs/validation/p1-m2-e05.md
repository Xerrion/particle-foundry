## Implemented contract

[`PressureFields`](../../engine/crates/sim-cpu/src/fluid.rs) validates and owns
cell density and pressure, staggered face velocity and aperture, grid geometry,
and declared boundaries for each CPU reference session. Invalid lengths,
non-finite values and movement through blocked or closed faces are rejected.

The [MAC operators](../../engine/crates/sim-cpu/src/operator.rs) use matching
aperture weights for divergence and pressure gradient. Open-boundary operators
accept an explicit face flux and use reservoir pressure at a half-cell distance.
The [matrix-free assembly](../../engine/crates/sim-cpu/src/assembly.rs) uses
cell-derived face density and sealed connected components. The
[bounded solver](../../engine/crates/sim-cpu/src/solver.rs) applies gravity,
solves the sealed pressure correction, checks the scaled residual and an
independently recomputed corrected-velocity divergence, and returns no
candidate on failure. The CPU session caches assembled coefficients by geometry,
boundary, aperture and density revisions; pressure- or velocity-only changes
reuse the assembly.
