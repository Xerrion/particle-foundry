# P1 / M3 / E08 experimental browser scene evidence

**Status:** E08 validated locally on 29 September 2026. This is local evidence
on branch `codex/wasm-port-new-structure` at implementation commit `3bd1a6f`. The
480 x 270 scene completed 120 outer ticks on native Metal and 60 outer ticks
in required-GPU Chrome. Full `mise run ci` passed locally. The live sandbox
remains on the TypeScript backend.

## Frozen first scene and GPU ownership

The [scene seed](../../engine/crates/sim-gpu/src/scene/demo.rs) uses a 480 x 270
grid, one 13-row water pool, carrier air, fixed side walls and floor, passive
markers, gravity and a 0.002 m/s local velocity loop. It passes host and f32
seed validation. The [renderer](../../engine/crates/sim-gpu/src/render.rs)
samples the committed component-major mass buffer and fixed-wall headers on
the simulation device. It does not map the world to JavaScript for a normal
frame. A native offscreen fixture checks water, air, wall, viewport and
repeat-render pixels. Linear display colors require a non-sRGB render target.

The browser [canvas surface](../../engine/crates/sim-gpu/src/surface.rs) obtains
a compatible WebGPU adapter for the canvas before constructing its device.
It checks initial and resized backing dimensions against the device texture
limit, reports device-loss signals, and acquires frames for rendering on that
same device. A required-GPU browser smoke on Headless Chrome 154 used
`BrowserWebGpu` to construct this surface, render the committed seed, queue
a reset during a bounded advance, reject the stale reply, and render the new
epoch. Its ignored result is
`artifacts/validation/e08/browser-surface-pre-solver-2026-09-29/result.json`.
The required-GPU readback run accepted two full-size ticks, rendered their
committed frames, sampled three individual cells, captured one explicitly
requested committed generation and rejected stale probe/capture results after
reset. Its ignored result is
`artifacts/validation/e08/browser-readback-2026-09-29/result.json`.
The later balanced-build sustained run accepted 60 full-size browser ticks;
its result is
`artifacts/validation/e08/browser-sustained-balanced-2026-09-29/result.json`.
The command was `bun web/scripts/test-browser.ts artifacts/validation/e08/browser-sustained-balanced-2026-09-29 --require-gpu --sustained-gpu`.
Runtime device-loss injection remains pending. The live sandbox still selects
its legacy Canvas 2D context.

The opt-in page at `web/gpu.html` exposes pause, resume, reset, one-cell
inspection and a bounded water/air brush. It pauses while hidden and requires
an explicit resume when visible again. Both paint's coordinate control and
canvas pointer path changed
the committed rendered image on BrowserWebGpu without advancing tick or model
time. Its isolated Chrome result is
`artifacts/validation/e08/paint-ui-check-output/result.json`. The page is
limited to this M3 scene and does not select the live sandbox backend.
Another isolated Chrome run inspected an air cell, a water cell and a wall
cell, then painted water into the air cell and inspected its changed inventory
without advancing tick or time. At a 375-pixel viewport, the controls remained
visible without horizontal overflow. Hiding the tab stopped scheduled steps;
returning left the scene paused until an explicit Resume. The result and narrow
viewport image are in
`artifacts/validation/e08/inspect-visibility-ui-2026-09-29/`.

The [probe](../../engine/crates/sim-gpu/src/probe.rs) maps 16 bytes for one
selected cell. Its stamp includes epoch, tick, accepted time, generation and a
revision that increments for accepted substeps and zero-time paints. The owner
rejects a probe after an intervening reset. The explicit
[capture prototype](../../engine/crates/sim-gpu/src/checkpoint.rs) maps
3,631,800 bytes of five dynamic fields for one committed generation, then
returns a 3,631,908-byte `PFCP` version-zero diagnostic record. It has no
load API and is not the durable `PFSN` recovery format planned for E13.
No normal frame or accepted step invokes this full-state capture. The browser
smoke verifies the returned length, dimensions, epoch, tick and revision.

## Full-size solver investigation

On native Metal, the initial scene renders the expected air, water and wall
pixels. Before the hydrostatic pressure start, its first coupled outer tick
rejected after zero accepted substeps. Pressure exhausted the 512-iteration
cap at scaled true residual
`0.00012361744`, above the frozen `1e-5` tolerance. The probe took about
`0.361` s. Committed epoch, tick, accepted time, generation and sampled air,
water and wall pixels are identical before and after rejection. This is a
failure-isolation result, not a successful 480 x 270 simulation or throughput
measurement. An exact local-diagonal preconditioner was tested and did not
pass the gate; it was reverted. A read-only f64 reconstruction reproduced the
slow residual convergence of the native GPU solve. An isolated cfg(test)
hydrostatic initial-pressure probe then accepted the first full-size tick in
one substep at zero PCG iterations, scaled true residual `8.835308e-6` and
scaled divergence `8.828162e-6`, in about `0.033` s. It uses the same face
density as gravity and pressure correction and keeps both frozen gates. This
probe was moved into the production pressure path. Keeping its segment-top
reference for nonzero-gravity solves avoids f32 cancellation from a final
component-mean shift. Zero-gravity solves retain the component-mean gauge.
The browser accepted tick 1 at `0.016666666666666666` s with scaled true
residual `5.563101e-6` and divergence `5.5564506e-6`, then tick 2 at
`0.03333333333333333` s with residual `3.9778242e-6` and divergence
`3.980501e-6`. Both used the unchanged `1e-5` gates. The required-GPU smoke
also rejects fractional and wrapped numeric commands at both the TypeScript
adapter and raw WASM boundary.

A temporary native second-tick probe then rejected the viscosity candidate
with status 1 before pressure. A test-only readback found density
`1.1999995` kg/m3 at sealed pure-air cell zero, below the nominal `1.2`
kg/m3 minimum by five f32 ULP. The candidate's minimum density remained
within the upstream `1e-5` relative volume-closure gate. The scene now uses
one conservative effective minimum derived from that gate for both CFL and
viscosity. The strict viscosity shader still rejects a materially low density
(`1.19` kg/m3 in the focused regression). The native and browser two-tick
checks pass. A later required-GPU sustained probe completed three outer ticks,
then rejected tick 4 with transport volume-closure status 8. Its failed result
is `artifacts/validation/e08/browser-sustained-diagnostic-2026-09-29/result.json`.
Native investigation identified cumulative shared-face flux error. A local
face correction met the unchanged `1e-5` cell-closure gate through 14 ticks.
The next native and browser runs rejected tick 15 at pressure residual
`1.4596484e-5`, after the 512-iteration cap. A 1024-iteration native probe
returned the same residual. At the worst air cell, one f32 ULP of absolute
pressure could change the scaled stencil residual by about `1.77e-5`.
The browser result and pressure probe are in
`artifacts/validation/e08/browser-sustained-transport-2026-09-29/result.json`
and `artifacts/validation/e08/pressure1024-scratch/`.

The solver now stores its hydrostatic base separately from the dynamic
pressure correction. A native 4 x 3 variable-density gravity fixture and all
nine native pressure tests pass. The internal PCG stop margin is half of the
frozen final thresholds. The final residual and divergence gates remain
`1e-5`, with the 512-iteration cap unchanged. Transport now uses a corrected
shared-face ledger and per-donor two-outlet budget. The Y budget uses inventory
after the X transfer. A balanced clock split avoids a tiny last substep.
These changes address the failures above without relaxing their acceptance
gates. The [E07 evidence](p1-m3-e07.md) records the focused fixture values.

On the current local source, native Metal completed 120 outer ticks in 147
accepted substeps over 2.0 model seconds. The maximum recorded pressure
residual was `4.9995274e-6`; the maximum corrected divergence was
`5.0218528e-6`. The balanced-build required-GPU Chrome run completed 60
outer ticks. Its 58-tick sustained segment advanced `0.9666667` model seconds
in `0.4477` wall seconds, or `2.159` model seconds per wall second. Advance
latency was 7.8 ms at p50 and 9.3 ms at p95. The first two ticks copied 248
bytes of compact GPU-to-host completion records; the remaining 58 copied
7,896 bytes. These counts exclude GPU-internal copies, command uploads,
rendering and the explicitly requested full-state capture.

## Limits and later gates

Full `mise run ci` passed on the stable local working tree on 29 September 2026;
the ignored log is `artifacts/validation/e08/ci-final-2026-09-29.log`.
The required-GPU sustained run above was separate from CI. Runtime device-loss
injection and recovery remain for E13. The prototype capture has no load path
and does not provide E13 recovery. Remote CI has not been established by these
local checks. The live sandbox continues to use the legacy backend.
